トレードで利益を出すことを主目的とせず、Python・Git/GitHub・データ分析・テスト・設計・AI活用の実践的な経験を積むことを目的とする。

## やらないこと

- 利益を目的にしない（エンジニアリング力の獲得を優先する）
  - 理由1：利益を目的にすると「なぜ動くか理解しないまま、結果的に儲かったコード」を採用する誘因が生まれる。これは個別株のバックテストにありがちな「カーブフィッティング（過去データに都合よく当てはめただけで、将来機能しない）」という典型的な失敗パターンに直結する
  - 理由2：損益を評価軸にすると、初期の失敗（当然多い）がそのまま「プロジェクトの失敗」に見えてしまい、継続のモチベーションを削る。2026-06-20の時点で「長続きせず飽きてやめること」を自分自身が最大の懸念として挙げていたので、評価軸をエンジニアリング力（テスト・設計・検証プロセス）に置くことは、その懸念への構造的な対策でもある
  - 理由3：就活で語る場合、損益の数字自体は第三者が検証できない弱い証拠（運の可能性を排除できない）。テスト・設計判断・デバッグ過程の方が再現性・説得力のある証拠になる
- 実際の資金を使うのは、バックテスト・ドライラン実績・リスク管理（ストップロス／ポジションサイズ上限）が揃ってから（詳細はVISION.md）
