# プロジェクト名

## 目的

金融市場を題材として、エンジニアリング力を身につける。

トレードで利益を出すことを主目的とせず、Python・Git/GitHub・データ分析・テスト・設計・AI活用の実践的な経験を積むことを目的とする。

- Python

- データ分析
- AI活用
- AIエージェント
- テスト

- 基礎的な機械学習

## 作るもの（段階的に進める）

### Phase1：データ収集

- 日本株の株価を取得する
- ニュースを取得する
- データを保存する

### Phase2：分析

- 指標を計算する
- グラフ化する
- 複数銘柄を比較する

### Phase3：検証

- バックテストを実装する
- バイアスの影響を可視化する

### Phase4：エージェント化

- 定期実行する
- 分析結果をまとめる
- 理由を説明できるエージェントを作る
